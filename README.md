# あんしんQR

QRコードを読んで、**どこへ行くかを先に見せる**、広告なしのシンプルな QR リーダー。
お店の注文・名刺・Wi-Fi・電話番号・ホームページ など、ふだん出会う QR を全部これ 1 つで。
読んだ内容は スマホの中にだけ残り、**どこにも送らない**。

**使う: https://roguepink.github.io/QR/**

## 使い方

1. 開くと カメラが動く。QRコードを 黄色いわくの中に入れるだけ(「ピッ」と鳴って ぶるっとする)
2. 読めると「どこへ行くか・何が書いてあるか」を大きく見せる。**勝手には開かない**
3. 確かめて、大きなボタンを押す(「開く」「電話をかける」「連絡先に保存」「パスワードをコピー」など)
4. 「もう一度 読む」で次へ

- **💡 ライト**: 暗い店内で(対応しているカメラのみ)
- **🔍 拡大**: 名刺の小さい QR に
- **🖼 写真から読む**: LINE やメールで届いた QR は スクショを撮って読む
- **さいきん読んだもの**: 最近 20 件。タップで もう一度 開ける。「消す」で全部消える(スマホの中だけ)
- **🔔 音**: 読めたときの音の あり/なし

## 読める種類と、出るボタン

| 種類 | 見分け方 | 出るもの |
|---|---|---|
| 🌐 ホームページ(注文・メニュー・決済・LINE 友だち追加・SNS など) | `https://…` `www.…` | 行き先(ドメイン)を大きく、全文、安全チェック、「開く」「コピー」「LINEなどで送る」 |
| 📶 Wi-Fi | `WIFI:` | ネットワーク名・パスワード、「パスワードをコピー」、つなぎ方 |
| 👤 名刺・連絡先 | `BEGIN:VCARD` / `MECARD:` | 名前・会社・電話・メール・住所、「電話をかける」「メールを書く」「地図で見る」「連絡先に保存」 |
| 📞 電話番号 | `tel:` / 数字だけ | 「電話をかける」(押すと発信の確認が出る) |
| 💬 SMS | `SMSTO:` / `sms:` | 「SMS を書く」 |
| ✉️ メール | `mailto:` / `MATMSG:` | 「メールを書く」 |
| 📍 場所 | `geo:` | 「地図で見る」(Google マップ) |
| 📅 予定 | `BEGIN:VEVENT` | 内容を表示、全文コピー |
| 📝 文字 | それ以外 | 文字を表示、コピー、送る |

PayPay など決済の QR は、ふつうのホームページ(`https://qr.paypay.ne.jp/…`)なので「開く」で PayPay アプリが立ち上がる。
新幹線・飛行機の QR(改札でかざすもの)や 電子処方箋の引換番号は、中身が「文字」として出るだけ(それで正しい)。

## 安全チェック(クイッシング = QR 詐欺 対策)

QR は人の目では中身が読めないので、**開く前に「行き先」を見せる**のがいちばんの対策。そのうえで:

- ⛔ **開かない**: `javascript:` `data:` `intent:` `file:` など、ホームページではないアドレス
- ⚠️ **あやしい(開かないことをおすすめ)**: アドレスに「@」がある / 数字だけ(IP アドレス) / 外国の文字をまねた `xn--` / `paypay` `line` `amazon` などの有名な名前が入っているのに 本物のドメインではない
- ⚠️ **気をつける**: 暗号化されていない `http:` / 短縮アドレス(bit.ly など。行き先が隠れている) / 「.」がとても多い / とても長い
- ✅ **よく知られたサービス**: LINE・PayPay・YouTube・ヤマト運輸 など 約 40 の本物のドメインに完全一致したときだけ名前を出す(似せた名前は一致しない)

「あやしい所は見つかりませんでした」は「安全です」ではない。画面にも「行き先が お店や相手の名前と合っているか 確かめてから」と出す。

## しくみ

- `index.html` 1 枚 + `lib/jsQR.js`(QR を解読する公開ライブラリ。Apache-2.0、`lib/LICENSE-jsQR.txt`)。ビルドなし・CDN なし・外部通信なし(ページを取りにいく GitHub Pages 以外)
- 解読: ブラウザに内蔵の `BarcodeDetector`(Android の Chrome など)があればそれ、なければ `jsQR`。どちらも端末の中だけで動く
- 昔の Shift_JIS の名刺 QR(ガラケー時代の MECARD)も、`TextDecoder('shift_jis')` で読み直す
- 読めたらカメラを止める(電池・プライバシー)。「もう一度 読む」で再開。ほかのアプリに切り替えると止まり、戻ると再開
- 「🔍 拡大」は映像の真ん中を切り取って解読する(どの端末でも同じに動く)
- `manifest.webmanifest` + `sw.js` で ホーム画面に入れられ、電波がなくても起動する
- 画面の部品: `Parse`(文字の分類と安全チェック。純粋な関数で、`window.QRParse` からテストできる)/ `Camera` / `UI`

## 確認用

- アドレスの末尾に `#test=<文字>` で、カメラなしで結果画面が見られる(例: `index.html#test=WIFI:S:abc;P:123;;`)
- `_check/`(Git に入れない)に Playwright のテスト。`~/.claude` のスクラッチにある `test_decode.py`(24 種類の QR 画像を「写真から読む」で読む)と にせカメラ(`--use-file-for-fake-video-capture`)のテスト
- 読めないもの: Micro QR(小さい規格。jsQR も iPhone も非対応)、バーコード(JAN など。このアプリは QR 専用)

## 対応

- iPhone: Safari(iOS 15 以上を想定)。ホーム画面に入れても カメラが使える
- Android: Chrome
- **LINE の中で開くと カメラが使えないことがある**。メニューから「Safari で開く」/「他のアプリで開く」→ Chrome。画面の上に案内が出る
- カメラは `https` でしか動かない(GitHub Pages は https)

## 直して公開するとき

- `main` に push すれば公開される(GitHub Pages)。開いた人は 次に開いたとき新しい版になる
- `sw.js` の `VERSION` を上げるのは、覚えるファイル(`FILES`)や `manifest.webmanifest` を変えたときだけ
- Chrome が「すでにインストールされています」と言うときは `manifest.webmanifest` の `id` を変える
