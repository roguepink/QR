使い方

1. アプリを開くと カメラが動きます。QRコードを 青いわくの中に 入れるだけ。

2. 読めると「どこへ行くか」「何が書いてあるか」を先に見せます。勝手には開きません。

3. 内容を確かめて、大きなボタンを押します(「開く」「電話をかける」など)。

読めないとき

  • 少し離す・近づける、まっすぐ向ける、明るくする(「💡 ライト」)
  • 名刺など小さいQRは「🔍 拡大」で大きくする
  • LINE やメールで届いたQRは、スクショを撮って「🖼 写真から読む」

カメラが動かないとき

  • iPhone: 設定 → アプリ → Safari → カメラ を「確認」か「許可」に。ホーム画面に入れたアプリなら 設定 → アプリ → あんしんQR → カメラ
  • Android: アドレスの左の 🔒 や ⓘ → 権限 → カメラ を「許可」に
  • LINE の中で開いているときは、メニューから Safari や Chrome で開き直す

安全のために

  • 読んだあとに出る「行き先」が、お店や相手の名前と合っているか 見てから開く
  • 貼ってあるQRの上に 別のシールが重ねてあったら 読まない(すり替えの手口)
  • 開いた先で パスワード・カード番号・暗証番号 を求められたら、いったん閉じて 誰かに相談する
  • このアプリは 読んだ内容を どこにも送りません。「さいきん読んだもの」も このスマホの中だけです

ホーム画面に入れる

iPhone(Safari): 共有ボタン → 「ホーム画面に追加」。Android(Chrome): メニュー(︙) → 「アプリをインストール」。入れると 全画面で すぐ開けます。
